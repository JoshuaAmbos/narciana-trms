# Narciana Tenant and Rental Management System

  

Web app for Narciana House Space Rental (Laravel 12 + Blade + MySQL/MariaDB), used in Chrome on an Android tablet.

  
  

## Local setup (Windows + XAMPP)

  

1. Start **MySQL** in the XAMPP Control Panel.

2. Create the databases (once):

```

C:\xampp\mysql\bin\mysql.exe -u root -e "CREATE DATABASE narciana CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE DATABASE narciana_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

```

3. Install and configure:

```

composer install

copy .env.example .env

php artisan key:generate

```

4. Create the tables and the staff accounts + default settings:

```

php artisan migrate

php artisan db:seed

```

Set `SEED_OWNER_PASSWORD` etc. in `.env` first, or copy the random passwords the seeder prints.

5. Sample rooms for testing only (never on the live hosting):

```

php artisan db:seed --class=DemoSeeder

```

6. Run: `php artisan serve`, then open http://127.0.0.1:8000

  

## Local setup (Ubuntu / Linux)

1. Start **MySQL** (using LAMPP or native MySQL):
   * For LAMPP:
     ```
     sudo /opt/lampp/lampp startmysql
     ```
   * For native MySQL:
     ```
     sudo systemctl start mysql
     ```

2. Create the databases (once):
   * For LAMPP:
     ```
     /opt/lampp/bin/mysql -u root -e "CREATE DATABASE narciana CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE DATABASE narciana_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
     ```
   * For native MySQL:
     ```
     sudo mysql -e "CREATE DATABASE narciana CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE DATABASE narciana_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
     ```

3. Install and configure:
```
composer install
npm install
cp .env.example .env
php artisan key:generate
```

4. Create the tables and the staff accounts + default settings:
```
php artisan migrate
php artisan db:seed
```
Set `SEED_OWNER_PASSWORD` etc. in `.env` first, or copy the random passwords the seeder prints.

5. Sample rooms for testing only (never on the live hosting):
```
php artisan db:seed --class=DemoSeeder
```

6. Run: `composer run dev` (or `php artisan serve`), then open http://127.0.0.1:8000

## Deployment on Render

The application includes an automated deployment pipeline configured for Render Web Services (`render.yaml`).

### 1. Web Service Settings
- **Environment**: PHP (`env: php`)
- **Region**: Singapore (`singapore`) or region closest to your database
- **Plan**: Starter
- **Build Command**:
  ```bash
  chmod +x bin/render-build.sh && ./bin/render-build.sh
  ```
- **Start Command**:
  ```bash
  heroku-php-nginx -C nginx.conf public/
  ```

### 2. Required Environment Variables
Configure the following environment variables in your Render dashboard or via `render.yaml`:

| Variable | Recommended / Default | Description |
|---|---|---|
| `APP_ENV` | `production` | Application environment |
| `APP_DEBUG` | `false` | Must remain `false` in production |
| `APP_URL` | `https://your-service.onrender.com` | Public URL generated by Render |
| `APP_KEY` | *(Auto-generated by Render)* | 32-character encryption key (`base64:...`) |
| `DB_CONNECTION` | `mysql` | Remote MySQL / MariaDB connection |
| `DB_HOST` | `<remote-host>` | Remote database host (e.g., Aiven, PlanetScale, Render) |
| `DB_PORT` | `3306` | MySQL port |
| `DB_DATABASE` | `<remote-database>` | Production database name |
| `DB_USERNAME` | `<remote-username>` | Database username |
| `DB_PASSWORD` | `<remote-password>` | Database password |
| `SESSION_DRIVER` | `database` | Retains user logins across ephemeral container restarts |
| `CACHE_STORE` | `database` | Stores cached keys in database table |
| `FILESYSTEM_DISK` | `s3` | Uses cloud storage for uploaded photos and receipts |
| `AWS_ACCESS_KEY_ID` | `<access-key>` | Cloudflare R2 / AWS S3 Access Key ID |
| `AWS_SECRET_ACCESS_KEY` | `<secret-key>` | Cloudflare R2 / AWS S3 Secret Access Key |
| `AWS_DEFAULT_REGION` | `auto` | `auto` for Cloudflare R2 or region for AWS S3 |
| `AWS_BUCKET` | `<bucket-name>` | S3 / R2 Bucket name |
| `AWS_ENDPOINT` | `https://<account-id>.r2.cloudflarestorage.com` | Custom endpoint for Cloudflare R2 or MinIO |
| `AWS_USE_PATH_STYLE_ENDPOINT` | `true` | Required for Cloudflare R2 and MinIO |

### 3. Ephemeral Disk & Remote Services Architecture
- **Stateless Web Tier**: Render web service containers are ephemeral. Any files written directly to local disk (outside `/tmp`) will be lost when the instance restarts or redeploys.
- **Persistent Sessions & Cache**: Handled automatically by the database tables (`sessions`, `cache`), preventing users from being logged out during container restarts.
- **Uploaded Assets**: Tenant MOAs, concern photos, and resolution proofs are stored on S3-compatible cloud storage (such as Cloudflare R2 or AWS S3) via Laravel's `s3` filesystem driver.
- **Automated Build Pipeline**: `bin/render-build.sh` automatically installs non-dev Composer dependencies, caches configuration/routes/views, and executes database migrations safely (`migrate --force`) during each deployment.
